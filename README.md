# Black Friday — барабан знижок For Men

Односторінковий сайт акції: відвідувач крутить барабан (раз на годину), отримує промокод, копіює його й вставляє в кошику на [for-men.ua](https://for-men.ua). У магазині — показує екран касиру.

## Як змінити промокоди

Усі призи барабана — у файлі `data/promocodes.json`. Барабан будується з нього автоматично, код міняти не потрібно.

Кожен запис — це **один сегмент барабана** (одна знижка) з кількома промокодами. Коли випадає знижка, клієнт отримує **випадковий** промокод з її списку.

```json
{
  "prizes": [
    { "discount": 30, "weight": 40, "codes": ["FM-FBX5M", "FM-26TC9", "FM-5QPZD"] },
    { "discount": 50, "weight": 10, "codes": ["FM-GFWPF", "FM-3YD8A"] }
  ]
}
```

| Поле | Обов'язкове | Що означає |
|---|---|---|
| `discount` | так | Розмір знижки у відсотках (від 1 до 100). |
| `codes` | так | Список промокодів цієї знижки (скільки завгодно, від одного). **Кожен має існувати як активний промокод з такою ж знижкою в адмінці for-men.ua**, інакше кошик його не прийме. Один і той самий код не можна використати у двох знижках. |
| `weight` | ні | «Вага» — як часто випадає ця знижка відносно інших. Зараз ваги в сумі дають 100, тож вага = шанс у відсотках. За замовчуванням `1`. |
| `label` | ні | Напис на барабані. За замовчуванням `-30%` тощо. Тримайте до ~10 символів. |

**Назви кодів не повинні підказувати знижку.** Не використовуйте `BF50` чи `SALE30`. Усі коди — одного формату й випадкові (`FM-` + 5 символів без схожих 0/O, 1/I/L), щоб їх не можна було вгадати.

### Під час акції

- **Код «витік»** (у адмінці різко зросла кількість застосувань): вимкніть його в адмінці й видаліть зі списку `codes`. Інші коди цієї знижки й далі випадатимуть.
- **Додати запасний код**: створіть його в адмінці з тією ж знижкою й допишіть у `codes`.
- Не видаляйте останній код знижки, бо тоді зникне весь сегмент барабана і зміняться шанси інших.

Некоректні записи й коди пропускаються (з попередженням у консолі браузера). Якщо коректних записів немає — сайт покаже повідомлення про помилку.

## Локальний запуск

Відкривати `index.html` напряму (подвійним кліком) не можна — браузер не дасть завантажити JSON. Запустіть локальний сервер:

```sh
python3 -m http.server 8000
```

і відкрийте http://localhost:8000.

Щоб покрутити барабан ще раз під час тестування — видаліть ключ `formen_bf_spin_v1` у DevTools → Application → Local Storage.
